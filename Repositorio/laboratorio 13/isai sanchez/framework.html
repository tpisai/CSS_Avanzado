Contenidos de los talleres

Diseño responsivo

Una interfaz responsiva adapta la distribución del contenido al espacio disponible. En esta versión se utiliza la rejilla de Bootstrap para organizar las tarjetas en una, dos o tres columnas.

Componentes reutilizables

Una tarjeta reúne una estructura de contenido y un conjunto de reglas visuales. Reutilizar el mismo patrón permite mantener una presentación coherente y facilita los cambios.

Acceso y mantenimiento

El contenido debe poder recorrerse con teclado, conservar un foco visible y seguir siendo legible al ampliar la página. Separar los ajustes del CSS del framework facilita su mantenimiento.
